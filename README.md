Installation Guide
For Termux (Android)
Copy and paste the command below into the Termux app and wait for the installation to complete:
```bash
cd && pkg install git -y && git clone https://github.com/teerateeranun0-art/sms-spam.git && cd sms-spam && bash install-termux.sh && cd

```
For Windows (PowerShell)
Copy and paste the commands below into PowerShell:
```bash
git clone https://github.com/teerateeranun0-art/sms-spam.git
cd sms-spam

```
How to Run
```bash
RUN-SMS-WEB

```
