Details of Operation Modes

Fast Mode

Risk: High
  • Send messages as fast as possible without waiting for responses
  • Uses Asyncio (parallel sending)
  • Pros: Very fast, sends a large number of SMS
  • Cons: Easy to get IP banned and may cause network congestion

Super Mode

Risk: Medium
  • Recommended! Intelligent system
  • Guarantees success according to targets
  • Automatically discards failed APIs
  • Pros: Accurate, doesn't waste time sending to dead numbers

Slow Mode

Risk: Low
  • Send messages slowly with delays
  • Most similar to human behavior
  • Pros: Safe, low chance of being banned
  • Cons: Very slow, suitable for long-running sessions
